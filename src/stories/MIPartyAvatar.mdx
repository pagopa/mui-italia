# MIPartyAvatar

MIPartyAvatar shows the logo of a public organization in a square badge. When no logo is available, it renders a neutral fallback icon so the layout stays stable and the user can still identify the context.

---

## Usage

- Use this component when you need to identify a party with a compact visual marker.
- Use the small size in dense lists and tables.
- Use the large size in headers or summary cards where the logo has more visual weight.
- Always provide meaningful alternative text for assistive technologies.

Do not use this component for product branding badges. For that use case, use MIProductAvatar.
