<Section title="Note per gli sviluppatori" description="API e integrazione.">
  <ul>
    <li>
      Importa <code>MIPaginationSelect</code> e <code>MIPaginationSelectProps</code>
      dall'entry point pubblico <code>@pagopa/mui-italia</code>.
    </li>
    <li>
      <code>options</code> usa il tipo <code>MISelectOption</code>: ogni opzione contiene
      value, label ed eventualmente disabled e startIcon.
    </li>
    <li>
      L API espone <code>options</code>, <code>value</code> e <code>onChange</code>,
      selezionate dalle props di MISelect tramite Pick, oltre a label e locale opzionali.
      Usa value e onChange per controllare la selezione dall'applicazione.
      Non sono presenti opzioni predefinite.
    </li>
    <li>
      <code>locale</code> accetta it (predefinito) ed en. Le label predefinite sono rispettivamente
      Elementi per pagina e Rows perpage. Una label personalizzata prevale sulla traduzione;
      se omessa, nulla, false o vuota viene usato il testo della lingua scelta.
    </li>
    <li>
      Il ref si riferisce al selettore interno. Lo stile e gestito dal componente;
      sx e le altre personalizzazioni di MISelect non sono esposte.
    </li>
    <li>
      Il componente non cambia automaticamente il numero di pagina e non modifica MIPagination.
    </li>
  </ul>

```tsx
import { MIPaginationSelect } from '@pagopa/mui-italia';

<MIPaginationSelect
  label="Righe per pagina"
  options={[
    { value: 10, label: '10' },
    { value: 20, label: '20' },
  ]}
  value={pageSize}
  onChange={(event) => setPageSize(Number(event.target.value))}
/>;
```
