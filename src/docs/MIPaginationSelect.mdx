<Section title="Note per gli sviluppatori" description="API e integrazione.">
  <ul>
    <li>
      Questo componente non è pensato per essere utilizzato al di fuori di <code>MIPagination</code>. Per questo motivo non è esportato come parte dell'API pubblica.
    </li>
    <li>
      L API espone <code>options</code>, <code>value</code> e <code>onChange</code>,
      selezionate dalle props di MISelect tramite Pick, oltre a <code>label</code> e <code>locale</code> opzionali.
      Senza una label personalizzata, il testo è «Elementi per pagina» per <code>locale="it"</code> (predefinito)
      e «Rows perpage» per <code>locale="en"</code>. Entrambe le props sono configurabili tramite
      <code>itemsPerPageOptions</code> di <code>MIPagination</code>.
      Usa value e onChange per controllare la selezione dall'applicazione.
      Non sono presenti opzioni predefinite.
    </li>
    <li>
      Il componente non cambia automaticamente il numero di pagina e non modifica MIPagination.
    </li>
  </ul>

```tsx
import { MIPagination } from '@pagopa/mui-italia';

<MIPagination
  count={pageCount}
  itemsPerPageOptions={{
    label: 'Righe per pagina',
    options: [10, 20],
    limit: pageSize,
    onLimitChange: setPageSize,
  }}
/>;
```
</Section>

<Section title="Accessibilita" description="Associazione della label e nome accessibile.">
  <ul>
    <li>
      Su desktop la label visibile è associata al combobox con un ID univoco.
      Su mobile la label non è visibile, ma viene usata come nome accessibile.
      È possibile impostare un nome diverso con <code>itemsPerPageOptions.inputProps['aria-label']</code>.
    </li>
    <li>Il menu conserva la gestione da tastiera del Select MUI-Italia.</li>
  </ul>

```tsx
<MIPaginationSelect
  label="Numero di righe per pagina"
  options={[{ value: 20, label: '20' }]}
  value={pageSize}
  onChange={(event) => setPageSize(Number(event.target.value))}
/>
```
