<Overview>
  <strong>MITable</strong> è il componente tabellare responsive del design system. Su viewport
  desktop usa la semantica nativa tabellare, mentre su viewport mobile trasforma ogni riga in una
  lista di coppie label/valore. Supporta azioni per riga, intestazioni ordinabili e paginazione
  opzionale.
</Overview>

<Section
  title="Accessibilità"
  description="L’accessibilità finale dipende dalla configurazione di label e azioni fornite dal consumatore."
>
  <SubSection title="Props rilevanti">
    <ul>
      <li>
        <strong>isAction</strong> sulle colonne: i contenuti interattivi delle colonne azione devono
        avere un nome accessibile appropriato, specialmente nei casi icon-only.
      </li>
      <li>
        <strong>renderCell</strong> su ciascuna colonna: in layout mobile il contenuto mostrato è
        interamente responsabilità del consumatore, inclusi eventuali label testuali o icone
        aggiuntive.
      </li>
    </ul>
  </SubSection>

<SubSection title="Semantica">
  In desktop MITable usa elementi nativi table, thead, tbody, tr e td. In mobile il layout è a
  blocchi, quindi la comprensione dipende dal contenuto reso in <code>renderCell</code>.
</SubSection>

  <SubSection title="Esempio accessibile">
    ```tsx
    const rows = [{ id: '1', status: 'Completed' }];

    <MITable
      columns={[
        {
          id: 'status',
          header: 'Status',
          renderCell: (row) => row.status,
        },
        {
          id: 'actions',
          header: '',
          isAction: true,
          renderCell: (row) => (
            <IconButton aria-label={`Open row actions for ${row.id}`}>
              <MoreVertIcon />
            </IconButton>
          ),
        },
      ]}
      getRowId={(row) => row.id}
      pagination={{
        count: 10,
        page: 1,
        onPageChange: () => {},
        itemsPerPageOptions: {
          options: [10, 24, 36],
          limit: 10,
          onLimitChange: () => {},
        },
      }}
    >
      {rows.map((row) => (
        <MITableRow key={row.id} row={row} />
      ))}
    </MITable>
    ```

  </SubSection>
</Section>
