<Overview>
  <strong>MIPagination</strong> e un wrapper di stile del componente Pagination di MUI pensato per
  gestire la navigazione tra pagine di una lista.
  <br />
  <br />
  Tramite la prop opzionale <strong>rowPerPageOptions</strong> espone anche un selettore del numero
  di elementi per pagina (basato su <strong>MISelect</strong>), visibile solo quando questa prop
  viene fornita.
</Overview>

<Section
  title="Elementi per pagina"
  description="Selettore opzionale del numero di elementi per pagina, visibile passando la prop rowPerPageOptions."
>
  <SubSection title="Props rilevanti">
    <ul>
      <li>
        <strong>rowPerPageOptions</strong>: se omessa, il selettore non viene renderizzato e
        MIPagination mostra solo la paginazione. Quando valorizzata, richiede un oggetto con:
        <ul>
          <li>
            <strong>limit</strong>: valore corrente selezionato, gestito dal consumatore
            (componente controllato).
          </li>
          <li>
            <strong>onLimitChange</strong>: callback invocata con il nuovo valore selezionato
            dall utente.
          </li>
          <li>
            <strong>options</strong>: elenco dei valori numerici proposti nel selettore. Se omessa,
            vengono usate le opzioni di default <code>[10, 24, 36]</code>.
          </li>
        </ul>
      </li>
      <li>
        Se <strong>limit</strong> non e presente tra le <strong>options</strong> disponibili (ad
        esempio dopo una modifica delle opzioni lato consumatore), MIPagination invoca
        automaticamente <strong>onLimitChange</strong> con il primo valore valido della lista.
      </li>
    </ul>
  </SubSection>

  <SubSection title="Esempio">
    ```tsx
    const [limit, setLimit] = useState(10);

    <MIPagination
      page={page}
      count={pageCount}
      onChange={(_, value) => setPage(value)}
      rowPerPageOptions={{
        options: [10, 24, 36],
        limit,
        onLimitChange: setLimit,
      }}
    />;
    ```
  </SubSection>
</Section>
