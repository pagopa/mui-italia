<Section
  title="Note per gli sviluppatori"
  description="Indicazioni tecniche per integrazione e configurazione."
>
  <ul>
    <li>
      La prop <code>rowPerPageOptions</code> è opzionale e abilita il selettore righe per pagina.
      Internamente alla prop si può inserire il numero di elementi per pagina con la prop{' '}
      <code>rowPerPageOptions.itemsPerPage</code>
      per avere il valore corretto delle righe nel selettore. Il valore di default di questa prop è 1
    </li>
    <li>
      Se il numero di rows calcolato dividendo <code>rowPerPageOptions.limit</code> per{' '}
      <code>rowPerPageOptions.itemsPerPage</code> non è presente nelle opzioni, il componente
      richiama <code>onLimitChange</code> con la prima opzione disponibile. Un esempio di{' '}
      <code>onLimitChange</code> è <code>(nextRow) => setLimit(nextRow * itemsPerRow)</code>
    </li>
    <li>
      Il componente puo essere usato in modalita controllata tramite <code>page</code> e
      <code>onChange</code>.
    </li>
    <li>
      La resa mobile dipende dal breakpoint <code>sm</code> del tema attivo.
    </li>
  </ul>
</Section>

<Section title="Note per i designer" description="Informazioni utili per la revisione visiva.">
  <ul>
    <li>Gli item pagina usano stati hover, selected e focusVisible con token del tema.</li>
    <li>Su mobile i numeri pagina non selezionati non vengono mostrati per ridurre ingombro.</li>
    <li>
      Il set viewport Chromatic proposto usa <code>componentMaxWidth = 1280</code> (euristica
      full-width) per coprire anche il comportamento responsive.
    </li>
  </ul>
</Section>

<Section
  title="Accessibilità"
  description="Elementi verificabili dal codice e dai test del componente."
>
  <SubSection title="Props rilevanti">
    <ul>
      <li>
        <strong>rowPerPageOptions.inputProps</strong>: consente di configurare attributi
        accessibili del selettore, incluso <code>aria-label</code>.
      </li>
      <li>
        La pagina corrente e marcata con <code>aria-current="true"</code> (comportamento
        verificato dai test).
      </li>
    </ul>
  </SubSection>

  <SubSection title="Esempio accessibile">
    ```tsx
    <MIPagination
      count={20}
      page={2}
      onChange={handlePageChange}
      rowPerPageOptions={{
        limit: 10,
        onLimitChange: setLimit,
        inputProps: {
          'aria-label': 'Seleziona numero di righe per pagina',
        },
      }}
    />
    ```
  </SubSection>
</Section>
