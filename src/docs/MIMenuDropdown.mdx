  <SubSection title="Props rilevanti">
    <ul>
      <li>
        <strong>items</strong>: contiene le voci del menu. Ogni voce richiede una <strong>label</strong>
        e una callback <strong>onClick</strong>, mentre <strong>icon</strong> è opzionale.
      </li>
      <li>
        <strong>onClose</strong>: chiude il menu e deve essere collegato all’azione di chiusura del
        contenitore del menu.
      </li>
    </ul>

<SubSection title="Comportamento del focus e della tastiera">
  Il componente eredita il comportamento di Menu e MenuItem di MUI, inclusi la navigazione da
  tastiera e la gestione del focus. Nel caso di interazioni con la tastiera, l’utente deve poter
  aprire, navigare e selezionare le voci con le modalità standard del menu.
</SubSection>

  <SubSection title="Esempio accessibile">
    ```tsx
    const [anchorEl, setAnchorEl] = useState<HTMLElement | null>(null);

    const handleOpen = (event: MouseEvent<HTMLButtonElement>) => {
      setAnchorEl(event.currentTarget);
    };

    const handleClose = () => {
      setAnchorEl(null);
    };

    return (
      <>
        <Button
          variant="contained"
          aria-controls={anchorEl ? 'mi-menu-dropdown' : undefined}
          aria-haspopup="true"
          aria-expanded={anchorEl ? 'true' : undefined}
          onClick={handleOpen}
        >
          Apri menu
        </Button>

        <MIMenuDropdown
          id="mi-menu-dropdown"
          open={isOpen}
          anchorEl={anchorEl}
          onClose={handleClose}
          items={[
            { label: 'Profilo', onClick: handleProfile, icon: <AccountCircleRounded /> },
            { label: 'Impostazioni', onClick: handleSettings, icon: <SettingsRounded /> },
          ]}
        />
      </>
    );
    ```

  </SubSection>
